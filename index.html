Frequently asked

How does hosting work?
Paste your HTML into the editor, pick an expiry, and hit Deploy. We save it to our database and give you a live URL like kayhosthtml.zone.id/site/abc123. Anyone with the link can view the page.
Which AI models are supported?
The AI visual editor uses Google Gemini 1.5 Flash. Click any element on your live preview, describe what you want to change in plain English, and the AI rewrites that part of the HTML.
Is it free?
Yes. Hosting is free. Sites expire after 7 days by default (or choose 1 day, 30 days, or never). No credit card, no signup required.
Do I need to sign up?
No. You can deploy without an account. Your sites are tracked by a random browser ID stored in localStorage, so you can still see your previously deployed pages.
Can I upload images?
Yes. Upload images via the file picker and we'll host them on Cloudinary, giving you a permanent URL you can use in your HTML.
Is there an API?
The deploy, list, and AI-edit endpoints are all REST APIs under /api. You can deploy programmatically by POSTing to /api/deploy.

API Docs

POST /api/deploy

Save HTML and get a live link. Body: { html, title, ttl, browserId }

GET /api/sites?browserId=xxx

List sites by browser ID.

POST /api/ai-edit

Send HTML + instruction to Gemini AI. Body: { html, selector, instruction }

POST /api/media

Upload image to Cloudinary. Body: { data, filename, mimeType }

POST /api/clone

Fetch a URL's HTML (SSRF-protected). Body: { url }

GET /site/:id

Serve deployed site's raw HTML.

How Pro works

  1. Sign in with Google, GitHub, or email — required so we know which account to mark as Pro.
  2. Click "Pay ₦10,000 with Paystack" — Paystack's secure popup opens, you pay with card or bank transfer.
  3. We verify the payment server-side (with Paystack directly — no manual check). The moment it's confirmed, your account is marked Pro.
  4. Refresh the page — all Pro features unlock: 30-day & Never TTL, Clone from URL, unlimited AI edits. Pro badge appears next to your name.

If you ever hit a Pro-gated feature without Pro, you'll see a small upgrade card explaining what you get. Payments are processed by Paystack — we never see or store your card details.

Common questions

Can I use Kayhost without paying anything?

Yes. Paste HTML, get a link — totally free. Sign in for free to get 7-day TTL and 10 AI edits/day. You only need Pro if you want sites to never expire, or to clone URLs.

What happens to my sites when Pro expires?

Your sites stay live — we never delete content without warning. New deploys will use Free-tier TTLs (1-day or 7-day if signed in). Email kayhost@admin.com to renew.

Do I need to share my AI key?

No. Free AI edits use Kayhost's shared Gemini key (limited per day). To go unlimited without Pro, paste your own OpenAI, Anthropic, or Gemini key in Settings → AI API Keys — it's stored in your browser only, never sent to our server.

Can I download the HTML I edited?

Yes — anyone, on any tier, can download whatever's in the paste box as a .html file. The Download button sits next to Deploy in the editor. Works after pasting, after AI edit, after Clone from URL, after loading any template.
